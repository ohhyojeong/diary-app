# 📔 Diary App

React로 만든 간단한 일기장 웹 애플리케이션입니다.  
React의 상태 관리와 CRUD 기능을 연습하기 위해 제작

## ✨ 주요 기능

- 일기 작성
- 일기 목록 조회
- 일기 상세 보기
- 일기 수정
- 일기 삭제

## 📚 구현하며 학습한 내용

- `useState`를 이용한 상태 관리
- `map()`을 이용한 데이터 렌더링 및 수정
- `filter()`를 이용한 데이터 삭제
- Spread Operator를 이용한 객체 및 배열 업데이트
- `onChange`, `onClick`, `onSubmit` 이벤트 처리
- 선택한 일기를 별도의 state로 관리
